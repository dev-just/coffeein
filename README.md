# Кофеин — портал поставщиков

Простой учебный проект на PHP и MySQL. В приложении есть регистрация, вход и управление поставщиками текущего пользователя.

## Запуск

1. Создать базу данных, импортировав файл `database.sql` через phpMyAdmin или командой:

   ```bash
   mysql -u root -p < database.sql
   ```

2. Скопировать `config.example.php` в `config.php` и при необходимости изменить параметры подключения к MySQL. Файл `config.php` содержит локальные настройки и не публикуется в Git.
3. Включить Apache-модуль `mod_rewrite` и разрешить `.htaccess` (`AllowOverride All`).
4. Указать папку проекта как корень сайта и открыть его в браузере.

Для встроенного PHP-сервера чистые адреса из `.htaccess` не работают. Проект рассчитан на Apache (например, OpenServer или XAMPP).
